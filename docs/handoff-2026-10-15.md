## 5. Invariants to preserve

1. **No archive rewrite.** Archives are append-only; readers sort in memory.
   Any change that rewrites `data/bars/` or `data/funding/` on disk needs
   explicit justification (backup + verification) — see the WS1 decision.
2. **No invented data.** Unavailable → explicit `None`/503, never a guess;
   no confidence/probability language (test-enforced in the promotion gate).
3. **Honest endpoints.** `/scanner-health` answers 503 UNAVAILABLE when no
   health source is wired — never a fake 200.
4. **Move-by-import.** The daemon loop body lives only in `proto/daemon.py`;
   `proto/service.py` imports it. No copied loop bodies.
5. **Stdlib only** in `proto/` (no new dependencies).
6. **Elapsed time on `time.monotonic()`**; wall clock only for absolute stamps.
7. **Call-shape decisions by `inspect.signature()`**, never by catching
   `TypeError` at a call site (that double-invoked a callback once already).
8. **Test style**: self-checking scripts with `check`/`FAILURES`/`ALL PASS`
   (not pytest); new suites are auto-discovered by `tests/run_all.py`.
   Network access in tests is tripwire-blocked (loopback only) — patch venue
   functions, never hit the network.
