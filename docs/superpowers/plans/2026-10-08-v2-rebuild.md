# Alt Radar v2 Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the scan loop and scoring inputs per spec while keeping the math library, ending with a scheduled, measurable scanner.

**Architecture:** Six sequential tasks: universe rotation first (fixes coverage without new deps), Bybit adapter (unlocks OI), MTF scoring (uses both), vetoes/flagging (uses scorer output), outcomes/collector wiring (uses stored signals + full universe), loop/TUI/errors (assembles all). Each task lands tested code on main.

**Tech Stack:** Python stdlib only (urllib, sqlite3, gzip, csv, concurrent.futures, curses). No new deps.

**Spec:** `docs/superpowers/specs/2026-10-08-alt-radar-v2-design.md` (v2, incl. r1 decisions + `is_actionable` naming fix)

## Global Constraints

- Read-only venue access, no orders/keys.
- Stdlib only.
- Score stays 0–100; alignment bonus `min(100, score+8)` applied after `base * earlyness`, before rounding.
- `flagged = is_actionable(stake) and score ≥ 24`; `is_actionable(stake) = self.actionable and (min_notional is not None and min_notional <= stake)`; `None` is fail-closed.
- Outcome bar mapping: entry = first 5m bar `ts > signal.ts`; horizon return from `fut[need-1]`; excursions over `fut[:need]`; horizons `{"1h":12,"4h":48,"24h":288,"7d":2016}`; `7d` from collector bars only.
- Collector covers FULL universe every 5m, per-coin CSV.gz with `ts,o,h,l,c,vol,amount`, dedupe by ts.
- 90s gate covers `scan_once` only; universe refresh cached 10 min.
- Concurrency: max_workers=12, 100ms stagger, 20 req/s cap, backoff 0.4s×2^attempt ×3 then counted failure.

## Review Focus

- Coin leaves rotation between signal and outcome — resolver must still find collector bars (covered by Task 5 test with rotated-out coin).
- `min_notional is None` coin with high score — must rank but never flag (Task 4 test).
- All three TF leans barely under 0.15 — no bonus, no crash (Task 3 test).
- Group shortfall (e.g. only 10 tradeable) — spill fills to 150, disjoint (Task 1 test).
- Bybit down — MEXC-only scoring continues, venue marked degraded (Task 6 test).
